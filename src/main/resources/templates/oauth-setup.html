🚀 Setup Google OAuth (Optional)

Step 1: Go to Google Cloud Console
Step 2: Create OAuth Client ID
  • Application type: Web application
  • Authorized redirect URI: http://localhost:8080/login/oauth2/code/google
Step 3: Copy credentials and restart Docker: 
docker-compose down
docker-compose up -d \
  -e GOOGLE_CLIENT_ID="your-real-client-id" \
  -e GOOGLE_CLIENT_SECRET="your-real-secret"

🐙 Setup GitHub OAuth (Optional)

Step 1: Go to GitHub Developer Settings
Step 2: New OAuth App
  • Homepage URL: http://localhost:8080
  • Authorization callback URL: http://localhost:8080/login/oauth2/code/github
Step 3: Set environment variables: 
export GITHUB_CLIENT_ID="your-client-id"
export GITHUB_CLIENT_SECRET="your-secret"
docker-compose restart

🎯 Alternative: Update docker-compose.yml

environment:
  - GOOGLE_CLIENT_ID=your-real-client-id
  - GOOGLE_CLIENT_SECRET=your-real-secret
  - GITHUB_CLIENT_ID=your-github-client-id
  - GITHUB_CLIENT_SECRET=your-github-secret
Skip OAuth - Test API Now System Health Check
